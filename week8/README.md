# SMP Daily AI Coach (Browser Tool)

A browser-based tool that predicts goal outcome with confidence score and coaching message. All JavaScript, no server.

## Features
- Predict goal with score /100
- Confidence %
- Smart coaching (111, 110, 101 logic)
- Session History log
- Runs 100% in browser

## How to use
1. Double-click index.html
2. Enter Sleep, Water, Steps
3. Click Predict My Day

## Tech
- HTML + CSS + Vanilla JS
- No backend

## Example
Input: 7h sleep, 8 water, 8000 steps
Output: Score 77, Hit YES, 77% confidence, Coaching: strong baseline
